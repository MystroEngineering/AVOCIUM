# AVOCIUM

Prototype de gestion de cabinet d’avocat (React + Vite).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir l’adresse indiquée par Vite (généralement http://localhost:5173).

## Modules
Tableau de bord, dossiers, clients, audiences, documents, facturation.

## Avertissement
Version de démonstration : données fictives enregistrées dans le stockage local du navigateur. Pas de connexion utilisateur ni de backend sécurisé. Ne pas utiliser avec des données juridiques réelles ou confidentielles.
